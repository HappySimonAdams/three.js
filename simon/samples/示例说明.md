# 示例说明

## 启动

* webgpu 示例使用 localhost 地址访问 (通过IP地址或127.0.0.1访问时 navigator.gpu 为 undefined 导致无法使用 WebGPU)

## 样例

* webgl_invisible_occlusion.html: 不可见遮挡
    * material.colorWrite = false;

* webgl_line_fat.html: 粗线
    * 顶点动态更新

* webgl_overlay_rendering.html: 覆盖渲染（线段）
    * 渲染顺序测试. 将顶点数据排好序后进行渲染
    * 使用 CPU 排序, 而不是在 Shader 中修改深度值

* webgl_shader_unroll_loop: Shader展开for循环
    * shader性能优化
